Charger les données en Python (Pandas)

Importez directement les observations publiées dans votre environnement Jupyter ou Colab.

import pandas as pd url = "http://127.0.0.1:8000/api/v1/observations?sector=agriculture&limit=5000" df = pd.read_json(url) print(f"Chargé {len(df)} observations") print(df.head()) temp_df = df[df['indicator'] == 'Daily mean temperature'] print(temp_df.groupby('region')['value'].describe())
